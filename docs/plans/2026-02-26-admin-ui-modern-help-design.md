# 管理后台 UI（现代简洁白底）+ 内置使用文档（静态）设计

日期：2026-02-26  
范围：仅后台（`/admin/*`）页面样式与信息架构；不改业务逻辑/数据结构

## 1. 背景与目标

当前后台沿用 H5 验证页的“移动端卡片风”，在桌面端观感与可用性较弱（窄宽度、控件不统一、导航重复）。

目标：
- 将后台改为「现代简洁白底」桌面布局（宽屏、分栏导航、统一按钮/表单/列表样式）。
- 在后台内置 **使用文档（静态写死）** 页面，指导“产品 → 批次 → 生成码 → 导出 → 配置验证页/内容/推荐”的完整流程。
- 不引入外部 CDN（避免依赖不稳定/受限），不增加前端构建步骤。

非目标（本期不做）：
- 权限系统拆分（管理员/运营）与多人账号。
- 富文本/WYSIWYG 编辑器（仍使用 textarea）。
- 后台改为 SPA（React/Vue）或引入复杂组件库。

## 2. 设计决策

### 2.1 模板组织
- 新增：`app/templates/admin/base.html`
  - 包含后台专用的 HTML skeleton 与 CSS
  - 统一：顶部栏 + 侧边栏 + 内容区
  - 仅在 `request.session.admin_logged_in == True` 时展示侧边栏与“退出”操作
- 所有后台页面改为继承：`admin/base.html`
- H5 验证页继续使用现有：`app/templates/base.html` 与 `verify.html`（不受影响）

### 2.2 视觉与布局（现代简洁白底）
- 页面背景：浅灰（提升层次），内容区：白底卡片（轻阴影/边框）
- 宽度：内容区最大宽度约 1100px，适配桌面；小屏自动收缩
- 组件风格：
  - Button：主按钮（蓝色）/ 次按钮（灰）/ 危险按钮（红，可选）
  - Form：label + input/textarea 统一样式、focus ring
  - List/Table：桌面端使用表格样式展示列表（产品、批次、推荐）

### 2.3 信息架构（导航）
侧边栏导航（登录后显示）：
- 仪表盘：`/admin`
- 产品：`/admin/products`（产品列表、编辑、进入批次）
- 验证页配置：`/admin/config`
- 固定内容：`/admin/content`
- 商品推荐：`/admin/recommendations`
- 使用文档：`/admin/help`

高亮规则：根据 `request.url.path` 前缀判断 active。

### 2.4 使用文档（静态）
新增页面：
- `GET /admin/help`（登录可见）
- 文档内容：
  1) 创建产品（名称、详情文字、上传图片）
  2) 创建批次（生产日期/备注）
  3) 生成防伪码（<=10000）
  4) 导出 CSV / 二维码 ZIP（二维码内容固定为 `https://1918imco.com/verify?code=...`）
  5) 配置验证页（显隐、阈值、文案、联系我们）
  6) 配置品牌溯源/关于我们 & 商品推荐位
  FAQ：一次扫码成功的定义（60 秒同设备去重）、重复扫码提示含义

## 3. 质量与验证
- 增加最小测试覆盖：
  - 未登录访问 `/admin/help` → 302/303 跳转到 `/admin/login`
  - 登录后访问 `/admin/help` → 200
- 现有测试保持通过（重点：`test_admin_auth` 对 `/admin` HTML 中链接存在性的断言）
